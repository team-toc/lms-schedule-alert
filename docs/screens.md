# 화면 목록 · 기능

화면 6개와 각 화면에 들어가는 것. 더 넣고 싶은 것, 빼고 싶은 것은 맨 아래에 적거나 회의 때 말한다. 이 목록 기준으로 할 일을 나눈다.

## 1. 로그인 · 회원가입

- 이메일 · 비밀번호 로그인, 회원가입(이름 추가)
- 한 번 로그인하면 30일 유지

## 2. 홈

- 위에 배너: 지금 제일 급한 것 하나 (바뀐 일정 / 가까운 마감)
- 오늘 일정: 수업 · 시험 · 내 일정. 바뀐 건 빨간 줄 + 반영 버튼, 겹치면 "겹침" 표시
- 다가오는 마감: 7일 띠 + D-day 목록
- 당겨서 새로고침

## 3. 캘린더

- 월간 달력, 날짜 밑 점 4색 (수업 · 마감 · 내 일정 · 변경됨)
- 날짜 누르면 그 날 일정 목록
- 내 일정 추가 · 수정 · 삭제

## 4. 알림

- 확인 필요: 시간 · 장소 바뀐 일정. 전 → 후 보여 주고 [캘린더에 반영] [나중에]
- 새 소식: 새 공지 · 새 과제
- 읽음 / 안 읽음, 푸시 알림

## 5. 설정

- 내 정보 (이름 · 학번 · 학과)
- 학교 LMS: Canvas 토큰 등록 · 해제, 가져오는 주기
- 캘린더: 구글 · 카카오 연결, iCal 주소 (폰 기본 캘린더용)
- 알림 켜고 끄기 (일정 변경 / 새 공지 · 과제 / 마감 하루 전)
- 로그아웃

## 6. 알림 · 일정 상세

- 전 → 후, 공지 본문 / 과제 설명, 반영 버튼, LMS에서 보기 링크

## 화면과 DFD 대응

| 화면 | DFD |
|---|---|
| 설정 (토큰 등록) | 1.0 LMS 동기화 |
| 알림 · 홈 배너 | 2.0 변경 감지 · 3.0 겹침 판단 · 4.0 알림 발송 |
| 알림 (반영 버튼) | 5.0 승인 처리 |
| 설정 (캘린더 연결) · 알림 (반영) | 6.0 캘린더 반영 |

## 같이 정할 것

- 로그인 없이 토큰만 넣고 바로 쓰는 방식도 둘지
- 알림 상세 화면을 따로 둘지, 목록에서 바로 처리로 끝낼지
- 내 일정은 앱에서 직접 추가할지, 구글 캘린더에 있는 걸 읽어 오기만 할지
- 주간 보기 · 다크 모드 · 위젯은 나중에
