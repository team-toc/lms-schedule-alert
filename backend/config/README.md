# 설정 파일

## class-periods.json — 교시 시간표

공지의 "3교시", "3~4교시"를 시각으로 바꿀 때 쓰는 시간표입니다 (ADR 0011). 서버가 시작할 때 읽고 검사하며, 틀리면 시작하지 않습니다.

저장소에는 **학교 실제 시간표 16교시**(서울 시간, 13교시부터 45분 수업)가 들어 있습니다(2026-11-19). 비어 있으면(`{ "periods": [] }`) 교시 표현은 **날짜만**(하루 종일 제안) 씁니다. 시간표에 없는 교시(예: 17교시)와 거꾸로 된 범위(예: 9~3교시)도 날짜만 씁니다.

JSON에는 주석을 쓸 수 없어서 형식은 여기에 적습니다.

```json
{
  "periods": [
    { "period": 1, "start": "09:00", "end": "09:50" },
    { "period": 2, "start": "10:00", "end": "10:50" },
    { "period": 3, "start": "11:00", "end": "11:50" }
  ]
}
```

위 값은 형식 예시이며 실제 학교 시간표가 아닙니다.

| 규칙 | 설명 |
| --- | --- |
| `period` | 정수, 1교시부터 빠짐없이 차례로 (1, 2, 3, …) |
| `start` · `end` | 서울 시각 `HH:mm` (두 자리, 00:00 ~ 23:59) |
| 시작 < 끝 | 한 교시의 `start`는 `end`보다 앞서야 합니다 |
| 겹침 없음 | 다음 교시의 `start`는 앞 교시의 `end`와 같거나 뒤여야 합니다 |

"3~4교시"는 3교시 `start`부터 4교시 `end`까지입니다.
